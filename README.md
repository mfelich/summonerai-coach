# SummonerAI Coach - *AI-powered League of Legends performance analyzer*

## Project Overview
SummonerAI Coach is a full-stack application that provides AI-driven performance analysis for League of Legends players. The system fetches player data and match history from Riot API, processes game statistics, and generates detailed performance analysis using OpenAI's GPT model.

## Key Features
- Riot API integration for real-time player data and match history
- AI-powered performance analysis using OpenAI GPT
- Player statistics processing and trend analysis
- Custom analysis reports with strengths, weaknesses, and improvement suggestions
